# Design system

A small set of tokens and components, all in [`site-src/css/style.css`](site-src/css/style.css). Use these when adding pages so everything matches. The look was designed in Claude Design and ported to plain HTML/CSS.

**Feel:** warm, calm and personable. Simple layouts, one accent colour, no badges or boasting. The work is the focus.

## Tokens

Defined as CSS variables at the top of `style.css`. Change them there and the whole site follows.

| Token | Light | Dark | Used for |
|---|---|---|---|
| `--bg` | `#faf6f2` | `#201c19` | Page background |
| `--surface` | `#ffffff` | `#2a2521` | Cards, header, dialogs |
| `--border` | `#e8e1d9` | `#3b342e` | Borders, dividers |
| `--text` | `#211d1a` | `#f3ede6` | Body text |
| `--text-muted` | `#6b6259` | `#b4a99d` | Tags, secondary text |
| `--accent` | `#ab4d1b` | `#e08a52` | Links, buttons, highlights |
| `--accent-soft` | `#f7e9df` | `#3a2a1f` | Callouts, pills, type labels |
| `--accent-text` | `#ffffff` | `#201c19` | Text on top of `--accent` |

Other tokens: `--font` (Sora, with system fallbacks), `--radius` (16px cards), `--radius-sm` (14px), `--max-width` (900px), `--max-width-narrow` (760px).

<details>
<summary><strong>▸ Why is the light accent darker than in the original design?</strong></summary>

The design's terracotta (`#c2622d`) measured 3.85–4.13 contrast against the background, below the 4.5 needed for small text to be comfortably readable. `#ab4d1b` looks almost the same but passes everywhere (5.1 on the background, 5.5 on white, 4.6 on the soft tint). If you change the accent, check contrast again against `--bg`, `--surface` and `--accent-soft`.

</details>

## Light and dark mode

- With no saved choice, the site follows the visitor's system setting.
- The header toggle sets `data-theme="light"` or `"dark"` on `<html>` and saves it in `localStorage` (`fte-theme`).
- A tiny inline script in `partials/head.html` applies the saved choice before the page paints, so there's no flash.
- Any new colours must be added for both themes (in the media query block and the `[data-theme="dark"]` block).

## Page shell

Every page starts with the shared head and nav partials and ends with the footer:

```html
<head>
<!--#include partial="head.html"-->
  <title>Page name — Fernando Teodoro</title>
</head>
<body>
<!--#include partial="nav.html"-->
<main>            <!-- <main class="narrow"> for reading pages -->
  ...
</main>
<!--#include partial="footer.html"-->
</body>
```

`head.html` brings in the font, stylesheet, theme script and `js/site.js`. The build adds `aria-current="page"` to the matching nav link automatically.

Use `<main>` (900px) for grids and hubs, and `<main class="narrow">` (760px) for reading pages like case studies and About.

## Components

| Component | Markup | Notes |
|---|---|---|
| Page heading + intro | `<h1>` then `<p class="tagline">` | Used on hub pages |
| Card grid | `<div class="card-grid">` | Auto-fits columns, minimum 260px |
| Card | `.card` > `h3`, `.card-tags`, `.card-hook`, `.card-link` | Featured items; Lab cards are generated by `build.py` |
| Card type label | `<span class="card-type">Tool</span>` | Above the card title; set with `type` in `lab-tools.json` |
| Project card + dialog | `.project-card` with a `.more-link` button and a `<dialog class="project-dialog">` | See `other-projects.html`. `js/site.js` opens it from `data-open="<dialog id>"` |
| Tags line | `<div class="tags">` | Under a case-study title |
| Button | `<a class="button">` | Primary action on case studies |
| Pills | `<a class="pill">`, `.pill.primary`, `.pill.outline` | Home-page links and the resume button. Wrap in `.pill-row` |
| Callout | `<div class="callout">` (or `.status-note`) | Highlighted note. In content, a Markdown quote block becomes one |
| Bullet list | `<ul class="project-bullets">` | Case-study lists. Markdown lists get it automatically |
| Back link | `<a class="back-link">` | End of a page |
| Links in text | plain `<a>` inside `<p>` | Underlined automatically |

Page text comes from `content/` (see [CONTENT.md](CONTENT.md)); the HTML around it lives in `site-src/*.html` and `site-src/templates/`.

## Lab tool pages

Lab tools live in their own repos and don't have to use this stylesheet (see [LAB.md](LAB.md)). If you want a tool to match the site, copy the token block from the top of `style.css` into the tool.

## Changing the look

- **Colours, fonts, corner radius:** edit the tokens.
- **A component's style:** edit its section in `style.css`.
- **A new design from Claude Design:** put its files in `design-input/` (git-ignored) and ask Claude to port it. The old design's tokens map onto this table.
