Acted as Product Owner for a 5-person capstone team building an image-annotation tool for C-LARA, an open-source language-learning platform. Owned the Django REST API (11 endpoints, 37-test suite) and co-built the React frontend with a teammate, including a stroke-stitching algorithm for freehand annotation. Graded H1, with strong feedback from C-LARA's technical client.
