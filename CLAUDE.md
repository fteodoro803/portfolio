# Portfolio

Static site: text in `content/`, page shapes in `site-src/`, `build.py` builds it into `dist/`. See [README.md](README.md).

## Putting a project on the portfolio

When asked to add a project, tool or demo to this portfolio, start from [LAB.md](LAB.md). For an app that runs on a server and sleeps when idle (Cloud Run and similar), read **"Putting a project on the portfolio"** there. It covers the steps, the entry page design questions and the template in `demo-entry/`. Help design the entry page with the person before writing it.

This applies from a chat in another repo too: read this repo's README.md and LAB.md by path.
